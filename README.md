# 🧠 Mental Health in Tech Workspace — Exploratory Data Analysis & Interactive Dashboard

![Python](https://shields.io)
![Streamlit](https://shields.io)

This repository contains a production-grade Capstone Project that analyzes **attitudes toward mental health and the frequency of mental health disorders in the technology workplace**. The project transforms raw survey data into clean insights using a Jupyter Notebook EDA pipeline and serves them through an interactive web-based Streamlit application.

## 🛠️ Local Environment Installation & Setup

Follow these quick steps to set up and run this project locally on your machine:

1. **Clone this repository onto your machine:**
   ```bash
   git clone https://github.com
   cd mental-health-survey-eda-analysis
   ```

2. **Install all required libraries at once:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Execute the Jupyter Notebook EDA Pipeline:**
   Open your development workspace environment (`jupyter notebook` or VS Code) and open `mental.ipynb` to step through data cleaning and view the **20 required charts** tracking Univariate, Bivariate, and Multivariate relationships.

4. **Launch the Interactive Streamlit Web App Interface:**
   ```bash
   streamlit run app.py
   ```

## 📈 Analytical Methodology & "UBM" Design Framework

This project strictly adheres to the **UBM (Univariate, Bivariate, Multivariate)** data storytelling guidelines to uncover actionable operational conclusions:

### 🧹 Automated Data Wrangling Actions
* **Age Outlier Purging:** Cleans invalid raw out-of-bounds inputs (e.g., `-1726`, `99999999999`) and normalizes records into a valid workforce boundary (18–75 years) using median imputation.
* **Gender Open-Text Standardisation:** Regulates loose user text variations (e.g., `male-ish`, `cis female`, `m`, `f`) cleanly into uniform category designations: `Male`, `Female`, and `Non-Binary / Diverse`.
* **Null Value Resolution:** Systematically fills empty text columns (like `work_interfere` and `self_employed`) using categorical fallbacks to prevent pipeline computation crashes.

### 📊 Comprehensive Visualization Matrix (20 Charts)
* **Univariate (Charts 1-6):** Baseline tracking across target metrics including overall care treatment rates, age density curves, corporate scale size splits, and geographical data clusters.
* **Bivariate (Charts 7-13):** Testing predictive dependencies like family health background profiles vs. care seeking choices, employee size vs. benefit visibility, and conversational comfort indicators with supervisors.
* **Multivariate (Charts 14-20):** Deep correlation matrix heatmaps, interaction check grids, and multi-facet graphs exploring security anonymity metrics across remote environments and organizational structures.

## 💡 Strategic Client Business Recommendations
Based on the data insights generated by this workflow, organizations can implement several core structural strategies to lower workplace stigma:
1. **Bridge Communication Gaps:** Build clear channels regarding health care options; data profiles show that "Don't know" is a highly frequent response regarding benefit visibility in smaller start-ups.
2. **Standardise Anonymity Frameworks:** Establish clear, legally grounded privacy guardrails for remote and in-office contractors to increase their comfort when utilizing available resources.
3. **Equip Managers with Active Protocols:** Provide direct managers with structured communication paths to transform high care-seeking rates into positive performance outcomes.
